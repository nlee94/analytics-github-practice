# data/

## What is committed here, and what is not

| Path | Committed? | Why |
|---|---|---|
| `data/sample/*.csv` | Yes | Tiny (< 100 rows), synthetic, regenerated by `python/make_sample_data.py`. Lets queries and tests run anywhere. |
| `data/raw/`, `data/interim/`, `data/processed/` | **No** (ignored) | Real extracts are large, change constantly, and are often confidential. The warehouse is the system of record; the repo stores the *code* that produces data. |
| `outputs/`, `*.parquet`, `*.xlsx` | **No** (ignored) | Regenerated from code. If leadership needs a snapshot, tag the commit that produced it (Session 11). |

Rule of thumb: if a file would embarrass you in a public repo, or is bigger than a
screenshot, it doesn't belong in Git. Git also refuses files over 100 MB; use Git LFS
for genuinely versioned binaries, and a data store for data.

## Data dictionary

### `flights_sample.csv` — one row per scheduled flight

| Column | Type | Meaning |
|---|---|---|
| `flight_date` | date | Scheduled departure date |
| `flight_number` | text | Fictional carrier code `XA` + number |
| `origin`, `dest` | text | IATA airport codes |
| `aircraft_type` | text | Fleet type |
| `sched_dep_time` | text | Scheduled departure, local time `HH:MM` |
| `dep_delay_min` | integer, null if cancelled | Minutes late at departure (negative = early) |
| `arr_delay_min` | integer, null if cancelled | Minutes late at arrival |
| `cancelled` | boolean | `true` if the flight did not operate |
| `cancel_reason` | text, null unless cancelled | Weather / Maintenance / Crew / Air Traffic Control |

### `audit_findings_sample.csv` — one row per audit finding

| Column | Type | Meaning |
|---|---|---|
| `finding_id` | text | Unique id `F-2026-NNN` |
| `audit_id` | text | The audit that raised the finding |
| `audit_date` | date | Date of the audit |
| `area` | text | Ground Ops / Maintenance / Flight Ops / Cabin Safety / Training / Security |
| `severity` | text | Low / Medium / High |
| `status` | text | Open / In Progress / Closed |
| `opened_date` | date | When the finding was raised |
| `closed_date` | date, null unless Closed | When it was closed |
| `owner_team` | text | Team accountable for closing it |
